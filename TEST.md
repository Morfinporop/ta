# Testing Guide

## Проверка основных функций

### 1. Регистрация
- Откройте http://localhost:3000/register
- Заполните все поля:
  - Username: testuser (только латиница, цифры, _)
  - Display Name: Test User
  - Email: test@example.com
  - Password: testpassword123
  - Confirm Password: testpassword123
- Нажмите "Зарегистрироваться"
- Должна произойти регистрация и переход на главную страницу

### 2. Вход
- Откройте http://localhost:3000/login
- Введите email или username
- Введите пароль
- Нажмите "Войти"

### 3. Загрузка видео
- Авторизуйтесь
- Перейдите на /upload
- Перетащите видео файл или выберите через кнопку
- Заполните название
- Выберите видимость
- Нажмите "Опубликовать"

### 4. Просмотр видео
- Откройте главную страницу
- Нажмите на любое видео
- Должен открыться видеоплеер
- Проверьте управление:
  - Пробел - play/pause
  - F - fullscreen
  - Стрелки - перемотка

### 5. Поиск
- Введите запрос в строку поиска
- Нажмите Enter или кнопку лупы
- Должны отобразиться результаты

## Частые проблемы

### Кнопка регистрации не работает
- Откройте консоль браузера (F12)
- Проверьте наличие ошибок JavaScript
- Убедитесь что все поля заполнены корректно
- Проверьте что username содержит только латиницу, цифры и _

### Видео не загружается
- Проверьте размер файла (максимум 10GB)
- Убедитесь что это видео файл
- Проверьте консоль сервера на наличие ошибок FFmpeg

### Видео не воспроизводится
- Дождитесь завершения обработки (статус должен быть "ready")
- Проверьте что HLS.js загружен
- Откройте консоль браузера на наличие ошибок

### Поиск не работает
- Убедитесь что есть видео в базе данных
- Проверьте что индексы созданы
- Попробуйте простой запрос (одно слово)

## Debug

Для отладки добавьте в консоль:
```javascript
// Проверить состояние приложения
console.log(store.getState());

// Проверить WebSocket
console.log(wsClient.connected);

// Проверить текущего пользователя
console.log(store.getState().user);
```
