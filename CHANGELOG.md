# Changelog

## Последние изменения

### Исправления

#### 1. Убраны Notifications
- Удалена таблица notifications из базы данных
- Убрана кнопка уведомлений из navbar
- Удалены все связанные функции и endpoints
- Очищен store от notifications state

#### 2. Исправлены ошибки миграций
- Добавлена обработка дубликатов при создании таблиц
- Изменен язык полнотекстового поиска с 'russian' на 'english'
- Убран COMMIT из блока try/catch для предотвращения ошибок

#### 3. Исправлен Rate Limiter
- Добавлен `app.set('trust proxy', 1)` для Railway
- Исправлена ошибка ValidationError с X-Forwarded-For

#### 4. Исправлен визуал (YouTube-подобный)

**Navbar:**
- Все элементы выровнены по высоте (40px)
- Поисковая строка и кнопка лупы одинаковой высоты
- Кнопки "Войти" и "Регистрация" одинакового размера
- Иконка загрузки 40x40px
- Аватар 36x36px с border

**Buttons:**
- Стандартная высота: 40px
- btn-sm: 32px
- btn-lg: 48px
- Все кнопки используют line-height вместо padding для центрирования

**Inputs:**
- Стандартная высота: 44px
- Убран внутренний padding по вертикали
- Используется line-height для центрирования текста

**Icons:**
- Все эмодзи заменены на SVG иконки
- Добавлены стили для правильного отображения SVG
- Иконки центрируются через flexbox

#### 5. Улучшена регистрация
- Добавлено логирование для отладки
- Улучшены сообщения об ошибках (на русском)
- Добавлен console.log для отслеживания процесса
